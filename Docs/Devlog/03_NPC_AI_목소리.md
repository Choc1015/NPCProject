이번엔 떠돌이 상인 대사에 **AI 목소리**를 입히는 것. 이번에도 내가 프롬프트로 시키고 → AI가 만들고 → 내가 한 것만 적음.

## 1. 어떻게 할지 먼저 물어봄

### 내가 쓴 프롬프트

> 이제 npc가 하는 말을 ai 목소리를 입힐거야 어떻게 하면 좋을까?

### AI가 알려 준 것

- 상인 대사는 대화 데이터에 이미 정해져 있으니까, 게임 중에 실시간으로 목소리를 만드는 것보다 **미리 TTS로 녹음해 두고 게임에선 파일만 트는 것**을 추천함. 지연 없음, 비용 한 번, 마음에 안 드는 줄만 다시 뽑을 수 있음
- 실시간 생성은 나중에 NPC가 AI로 자유롭게 대답하게 만들 때나 필요하다고 함
- 한국어 TTS 후보로 ElevenLabs, 타입캐스트, 네이버 클로바 더빙을 비교해 줌

### 내가 한 것

- 처음엔 "일단 타입캐스트로 해볼게"라고 했고, AI가 대사 6줄을 파일명·톤 메모랑 같이 **대본 표**로 정리해 줌
- 그러다 "ElevenLabs로 해보려는데 어떻게 하면 되는지 알려줘"로 바꿨음. AI가 목소리 고르기 → 모델(Multilingual v2) → 설정값(Stability, Similarity 등) → 다운로드까지 순서를 알려 줘서 그대로 따라 한 것

## 2. 첫 대사 하나만 먼저 적용

### 내가 쓴 프롬프트

> 일단 뭔가로 쓰고 첫번째 start보이스만 넣었는데 이것만 적용해봐

(대본 정리하다가 AI가 대사 오타 "해졌지 뭐가"를 찾아 줘서 "뭔가"로 고치라고 한 것도 같이)

### AI가 만들어 준 것

- ElevenLabs 무료 플랜은 MP3로 받아지는데 언리얼은 MP3를 못 읽어서, AI가 블렌더에 들어 있는 오디오 기능으로 **WAV로 변환**해 줌
- 대화 데이터의 대사마다 **음성 칸**을 추가하고, 상인 머리 높이에 소리 컴포넌트를 달아서 대사가 나올 때 상인 쪽에서 들리게 함. 멀어지면 작아지고, 다음 대사로 넘기면 끊기는 것
- 4번 대사 오타도 고쳐 줌

### 중간에 생긴 일

- 언리얼 MCP에 **소리 파일 임포트 기능이 없었음.** 그래서 WAV를 콘텐츠 브라우저에 끌어다 넣는 건 내가 했음
- C++ 헤더가 바뀌어서 빌드하려고 에디터를 한 번 닫아 줌

### 내가 한 것

- WAV 끌어다 넣고, 상인한테 말 걸어서 첫 대사 목소리 나오는 것 확인 → "잘 나와"

## 3. 나머지 대사까지

### 내가 쓴 프롬프트

> 5 VO_Merchant_More.wav 또 궁금한 건 있나? -> 또 궁금한 거 있나?로 대사 수정

> 6번째 대사도 "그래, 조심히 가게나. 다음에 또 보자고!" 이걸로 수정

음성 만들다 보니 말투가 어색한 대사가 있어서 문장을 내가 직접 바꿨음. AI는 대본이랑 게임 자막을 같이 고쳐 줌.

> 그리고 음성도 다 넣었어 wav로 바꿔주면 내가 넣어줄게

### AI가 만들어 준 것

- 나머지 MP3 5개를 WAV로 변환하고, 내가 언리얼에 넣은 뒤 대사 6개 전부에 음성을 연결해 줌

### 내가 한 것

- ElevenLabs에서 나머지 5줄 생성해서 넣고, 언리얼에 WAV 끌어다 넣음
- 선택지 다 골라 보면서 6개 음성 전부 나오는 것 확인 → "다 잘 나와"
