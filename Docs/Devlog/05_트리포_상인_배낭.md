지난번에 트리포로 바꾼 상인한테 아직 없던 것, **대사에도 나오는 배낭**을 붙이는 것. 배낭은 몸이랑 같이 리깅하면 휘어서 따로 뽑기로 했었음. 이번에도 내가 프롬프트로 시키고 → AI가 만들고 → 내가 한 것만 적음.

## 1. 순서부터 물어봄

### 내가 쓴 프롬프트

> 이제 가방 트리포로 뽑으려는데 순서 알려줘

### AI가 알려 준 것

- **상인 뽑았던 GPT 대화창에서 이어서** 배낭만 그리게 하는 영어 프롬프트를 줌. 같은 창이어야 그림체랑 색이 맞는다는 것
- 포인트는 **멜빵을 등판에 납작하게 붙여서** 그리게 하는 것. 배낭은 뼈에 붙이는 고정 소품이라 멜빵이 늘어져 있으면 몸을 뚫거나 허공에 뜸
- 트리포는 캐릭터랑 다르게 **스마트 메시, 폴리곤 15000, 텍스처 2K**. 움직이지 않는 소품이라 가볍고 면 정리 깔끔한 쪽
- 받으면 블렌더로 크기·원점 맞추고 → 언리얼에서 등뼈 소켓에 붙이는 데까지 AI가 하기로 함

## 2. 트리포 설정 화면 확인

### 내가 쓴 프롬프트

> 여기서 바꿔야할 설정

(트리포 스마트 메시 설정 화면 캡처를 같이 보냄)

### AI가 알려 준 것

- 화면 그대로 **쿼드, 15000, 생성 1개, P2.0**이면 된다고 함. 스마트 메시 전용 모델이라 H3.1이 안 보이는 게 정상이라는 것
- 그림에 명암이 꽤 들어가 있어서 **조명 제거는 꼭 켜라**고 함

### 내가 한 것

- GPT로 배낭 그림 뽑고 트리포에서 생성해서 받음

![트리포로 뽑은 배낭](https://media.githubusercontent.com/media/Choc1015/NPCProject/main/Docs/Devlog/images/05_tripo_backpack.png)

## 3. 언리얼에 넣고 등에 붙임

### 내가 쓴 프롬프트

> 자 가방압축 폴더니까 적용해줘

### AI가 만들어 준 것

- 압축 풀고 블렌더(백그라운드)로 열어 봄. 4방향 렌더로 **어느 면이 등에 닿는 면인지** 먼저 찾음
- 높이 65cm로 맞추고, 원점을 등판 가운데에 둠. 트리포가 앞뒤 두께를 **54cm**로 너무 두툼하게 만들어서 앞뒤만 0.65배로 눌러 35cm로 만듦
- 언리얼에 스태틱 메시로 임포트하고, 상인 메시의 **`Spine2` 뼈에 `BackpackSocket`** 을 만듦. 그래서 Idle·Talk 모션으로 상체가 움직이면 배낭도 같이 따라감
- BP_NPC_Merchant에 `Backpack` 컴포넌트를 추가하고 맵에 놓인 상인에도 적용함

![처음 붙인 모습](https://media.githubusercontent.com/media/Choc1015/NPCProject/main/Docs/Devlog/images/05_backpack_first.png)

### 중간에 생긴 일

- MCP에는 뼈 위치를 읽는 도구가 없어서, AI가 **소켓을 각 축으로 10m씩 옮겨 보고 액터 범위가 어디로 늘어나는지** 보는 식으로 뼈 방향을 알아냄
- 컴포넌트의 부착 소켓 칸도 MCP로는 못 바꿔서, 블루프린트 Construction Script에서 소켓에 붙이게 함

## 4. 위치는 내가 직접 맞춤

### 내가 쓴 프롬프트

> 위치 조정 필요

### AI가 알려 준 것

- 말로 방향을 알려 주거나, 스켈레톤 에디터에서 `BackpackSocket` 을 직접 끌어서 맞추는 방법(Add Preview Asset으로 배낭 미리보기)을 알려 줌

### 내가 한 것

- 스켈레톤 에디터에서 소켓을 직접 끌어서 위치랑 기울기를 맞춤

> 값을 조정했어 이것 기준으로 실행전 가방 위치도 바꿔줘

- 플레이할 땐 바뀐 위치로 나오는데 에디터 화면(실행 전)에선 예전 자리라서, AI가 맵에 놓인 상인을 새로고침함. Construction Script로 붙인 거라 에디터가 바로 다시 계산 안 할 때가 있다는 것

> 플레이어가 180도 돌아가긴했는데 내가 조정했고 나머지는 자로대

- 돌아간 건 내가 고쳤고 나머지는 잘 됨
