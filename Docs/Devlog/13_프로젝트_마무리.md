이 프로젝트를 여기서 마무리하는 편. 지금까지 만든 걸 한 번에 정리함. 코드·에디터 작업은 Claude(AI)가 Unreal MCP + Blender MCP로 하고, 나는 프롬프트로 시키고 모델·소리를 구해 오고 PIE로 확인하는 역할이었음.

> 오케이 다 되었고 여기 이 프로젝트를 마무리하자 개발일지 마무리하고

## 만든 것

- **기간**: 2026-10-31 ~ 2026-11-03 (4일), 커밋 50여 개, 개발일지 13편
- **플레이**: 1인칭으로 밤 숲속 야영지를 걸어 다니다가 떠돌이 상인한테 E로 말을 걸면 선택지가 있는 대화가 진행되는 것
- **C++ (핵심 로직)**
  - 상호작용: 화면 가운데로 2.5m 스피어 트레이스해서 말 걸 대상 찾기
  - 대화: 노드 ID로 이어지는 대화 데이터 에셋, 선택지 분기, 노드마다 목소리
  - NPC: 대사마다 말하는 애니메이션 중 하나를 골라 몽타주로 재생
  - HUD: 상호작용 안내, 대화창, 선택지 버튼
  - 발소리: 걸은 거리마다 랜덤 발소리
- **블루프린트·데이터**: 상인 BP, 대화 에셋, HUD 위젯, 입력 매핑
- **아트·사운드**
  - 상인: 트리포 H3.1로 뽑고 Mixamo로 리깅·애니메이션, 배낭은 소켓에 붙임
  - 소품·나무·바위: 트리포 (Gemini로 레퍼런스 그림 → 트리포 스마트 메시 → 블렌더에서 크기·원점 정리)
  - 바닥·하늘·벽·고사리·풀: Poly Haven 무료 CC0 사진 텍스처·모델
  - 모닥불: 나이아가라 불꽃 + 라이트 함수로 빛 일렁임
  - 목소리: ElevenLabs, 숲 소리·발소리: OpenGameArt CC0
