## 2. 저장이 안 되는 문제

- 맵을 저장하려는데 "failed to save" 창이 뜸

> 저장하려니까 이런 에러가 뜨는데 무슨 문제 있음?

- AI가 확인해 보니 언리얼 에디터가 같은 프로젝트로 두 개 열려 있었음. 한쪽이 맵 파일을 잡고 있어서 다른 쪽이 못 덮어쓴 것. 하나를 닫으니 저장됨

## 3. 대화창 자막 (되돌림)

> 이제 대화창을 영화 보면 나오는 자막처럼 처리해줘 선택지는 그냥 열로 정렬해서 선택할 수 있게 해줘

- AI가 대화창 박스를 없애고 화면 아래 가운데에 이름·대사만 그림자 넣어 띄우고, 선택지는 그 위에 한 줄씩 세움. 선택지 버튼 모양은 C++로 바꿔서 빌드함

> 아니다 롤백 원래 자막으로 가자

- 커밋 전이라 위젯이랑 C++ 파일만 git으로 되돌리고 다시 빌드함. 원래 대화창 그대로

## 4. 숲 소리와 발소리

### 내가 쓴 프롬프트

> 이제 몽환적인 판타지 브금과 플레이어가 걸을 때마다 걷는소리를 넣고 싶어

### AI가 만들어 준 것

- 발소리는 C++로 플레이어 캐릭터에 넣음. 1인칭이라 걷는 애니메이션이 없어서, 땅 위를 170cm 걸을 때마다 한 번, 점프 후 착지할 때 한 번 소리가 나게 하는 것
  - 소리 여러 개 중 랜덤으로 고르고 같은 소리가 연달아 안 나게 함. 음 높이도 걸음마다 조금씩 바꿔서 기계적으로 안 들리게 함
  - 걸음 간격·볼륨·음 높이 범위는 블루프린트에서 바꿀 수 있게 열어 둠
- 소리는 목소리 때처럼 ElevenLabs로 뽑자고 프롬프트까지 써 줌

### 내가 한 것

> ElevenLabs 말고 다른 방식으로 하자

- AI가 OpenGameArt에서 무료(CC0) 판타지 음악이랑 발소리 후보 링크를 찾아 줌

> 판타지풍 브금말고 숲속 브금으로 가자

- 음악 대신 밤 숲 환경음으로 바꿈. AI가 귀뚜라미 소리 같은 숲 소리 후보를 다시 찾아 줌
- 내가 직접 들어 보고 귀뚜라미 반복 소리 1개, 발소리 3개를 받아서 폴더에 넣음

> 넣었어

- AI가 블렌더로 WAV 변환하고, 발소리는 앞뒤 무음을 잘라 0.3초짜리로 다듬음
- 사운드 임포트는 MCP로 안 돼서 내가 콘텐츠 브라우저에 끌어다 넣음

> 넣었어

- AI가 숲 소리를 맵 전체에 반복 재생으로 깔고, 발소리 3개를 플레이어 블루프린트에 연결함
- PIE로 들어 보니 숲 소리가 커서 볼륨 위치를 물어봄

> 브금 소리 줄이려는데 어디서 줄여?

> 플레이어 발자국 소리는

- 숲 소리는 맵의 `Amb_ForestNight` 액터 Volume Multiplier, 발소리는 `BP_PlayerCharacter` Class Defaults의 Footstep Volume에서 직접 맞춤
