이번엔 그래픽 업그레이드 시작. 블렌더로 도형 조합해서 만든 로우폴리 상인을 **트리포(Tripo)로 뽑은 고퀄리티 애니 느낌 캐릭터**로 바꾸는 것. 이번에도 내가 프롬프트로 시키고 → AI가 만들고 → 내가 한 것만 적음.

## 1. 블렌더로 되는지부터 물어봄

### 내가 쓴 프롬프트

> 이제 그래픽 업그레이드를 할거야 고퀄리티의 맵과 캐릭터를 뽑을건데 물어볼게 블렌더에서 그정도 수준의 모델을 만들 수 있어? 아니면 트리포를 사용해야 할까?

### AI가 알려 준 것

- AI가 블렌더를 코드로 조작해서 만드는 방식은 **지금 같은 로우폴리 스타일이 한계**라고 솔직하게 말해 줌. 고퀄은 스컬프팅·리토폴로지·텍스처 베이킹을 손으로 다듬어야 해서 코드로는 잘 안 된다는 것
- 맵은 Megascans·Poly Haven, 캐릭터는 트리포, 실사 사람이면 MetaHuman을 추천해 줌

## 2. 트리포에 넣을 그림과 설정을 AI가 다 정함

### 내가 쓴 프롬프트

> 실사라기보다는 고퀄리티 애니 느낌으로 갈거고 모든걸 트리포로 만들어보자 캐릭터부터 만들고 맵을 만들건데 너가 트리포에서 어떤 명령어 또는 어떤 레퍼런스 그림으로 만들게 할건지 다 정해줘 레퍼런스 그림은 무료로 gpt에서 뽑는게 좋고

### AI가 만들어 준 것

- 대사 설정("모자가 다 해졌지", "등에 멘 이 배낭")을 반영한 **상인 디자인**: 해진 챙 넓은 모자, 겨자색 목도리, 짙은 초록 코트, 벨트 주머니
- **GPT에 넣을 영어 프롬프트** 4개 (정면 / 뒷면 / 옆면 / 배낭). 포인트는
  - Mixamo 리깅이 잘 되게 **T포즈, 7등신** (SD 비율은 리깅이 깨짐)
  - 트리포가 그림의 음영까지 텍스처로 구워 버리니까 **평면 셀 색감, 그림자 없음, 흰 배경**
  - 배낭은 몸에 붙이면 리깅 때 같이 휘어서 **따로 뽑기**
  - 같은 캐릭터가 나오게 **같은 GPT 대화창에서** 순서대로 뽑기

### 중간에 생긴 일

> 좀더 자세하게 말해줘 HD 모델인지 스마트 메시인지 등등 세부사항 까지

AI가 트리포 공식 개발 문서를 찾아서 옵션표를 만들어 줬는데, API에만 있는 옵션이 섞여 있어서 실제 화면이랑 안 맞았음.

> 여기서부터 설명이 모호한데 너가 아니면 내 구글을 보고 결정해

AI가 크롬으로 직접 보려고 했는데 크롬 확장이 연결이 안 돼 있었음. 그래서 **트리포 설정 화면을 캡처해서 보내 주는 것**으로 해결함. AI가 화면에 보이는 옵션 이름 그대로 하나하나 정해 줌

- HD 모델 (스마트 메시 X), 울트라 메시 품질 켜기, AI 완성 및 3D 강화 끄기
- 텍스처 4K, 조명 제거 켜기, PBR 끄기 (애니 느낌엔 금속/거칠기 맵이 오히려 플라스틱처럼 보임)
- 토폴로지 삼각형, 폴리곤 수 80000, 모델 H3.1

### 내가 한 것

- GPT로 레퍼런스 그림 뽑고, 트리포에서 위 설정대로 생성해서 받음

## 3. 리깅 지점 물어봄

### 내가 쓴 프롬프트

> 이렇게 받았는데 너가 압축 풀어보고 어디에 리깅지점을 둬야할지 알려줘

### AI가 만들어 준 것

- 압축 풀고 블렌더로 열어 보니 **키가 0.98m**로 작게 나와 있었음. AI가 1.75m로 맞추고 발을 원점에 두고, 텍스처를 넣은 **Mixamo용 FBX**를 만들어 줌
- 이 캐릭터 기준 **Mixamo 마커 위치**를 알려 줌
  - 턱: 수염 끝 말고 실제 턱 끝
  - 손목: 초록 코트 소매 말고 흰 셔츠 소매 끝
  - 무릎: 코트에 가려서 코트 끝단 조금 위
  - 사타구니: 벨트 주머니 바로 아래, 바지 갈라지는 곳

## 4. 리깅 사이트 고민

### 내가 쓴 프롬프트

> 일단 막사모에 안하고 actorcore라는 사이트에서 리깅을 했어 여기서 모션도 내가 만들까 생각 중인데 어떻게 생각해?

> free iclon으로는 못 만들어?

### AI가 알려 준 것

- ActorCore는 리깅이 좋고 대화 모션이 많지만 **모션 대부분이 유료**고, 직접 만들려면 유료인 iClone이 필요함
- 무료 iClone은 없고 **체험판만** 있음. 체험판은 FBX 내보내기 제한이 있다는 포럼 글들도 찾아 줌
- 직접 모션을 만들고 싶으면 영상 모션 캡처(내가 연기한 영상을 FBX로)를 추천해 줌

### 내가 한 것

> 흠 이러면 그냥 막사모로 하자고

- 결국 Mixamo로 리깅하고 Idle 1개, Talk 3개 받아서 넣음

## 5. 언리얼에 넣고 교체

### 내가 쓴 프롬프트

> 다 했음

### AI가 만들어 준 것

- 새 메시랑 애니메이션 4개를 언리얼에 임포트. **키 175cm, 손가락 뼈까지 65개** 다 들어옴
- 애님 블루프린트를 예전 상인이랑 같은 구조(Idle 반복 → 대사 나오면 Talk)로 연결하고, 상인 BP랑 맵에 놓인 상인을 새 캐릭터로 교체
- 예전 로우폴리 상인 에셋은 지우지 않고 남겨 둠

### 중간에 생긴 일

- 세션 시작할 때 언리얼 에디터가 안 켜져 있어서 **언리얼 MCP 연결이 실패한 채로** 남아 있었음. `/mcp`에서 다시 연결해 줌
- 애님 블루프린트는 MCP로 만들면 스켈레톤이 비어서 깨지는 문제가 있어서, **만드는 것만 내가** 스켈레톤 우클릭 → Anim Blueprint로 함

### 내가 한 것

- 플레이해서 말 걸어 보고 Talk 모션이랑 음성 같이 나오는 것 확인 → "확인했어, 잘 돼"
