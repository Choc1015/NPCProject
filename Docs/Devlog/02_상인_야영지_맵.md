지난번엔 떠돌이 상인이랑 대화하는 것까지 만들었음. 이번엔 그 상인이 있을 만한 **맵**을 만드는 것. 이번에도 내가 프롬프트로 시키고 → AI가 만들고 → 내가 확인하고 고친 것만 적음.

## 1. 상자 같은 맵 만들기

### 내가 쓴 프롬프트

> 자 다음은 맵을 만들건데 저 떠돌이 상인이 있을만한 맵을 만들자 맵은 상자 형식으로 만들어서 그 안에 플레이어랑 NPC가 들어가 있는거지 이해했어?

AI가 세부 사항을 선택지로 물어봐서 이렇게 고름.

- 장소: **숲속 공터 야영지**
- 크기: **작게 (약 20m × 20m)**
- 위쪽: **완전히 닫힌 상자**

### AI가 만들어 준 것

- **Blender로 모델 13종**: 바닥(가운데 흙 + 둘레 풀), 바위 절벽 벽, 나뭇잎 천장, 나무 2종, 바위 2종, 모닥불, 천막, 통나무 의자, 상자, 통, 짐수레
- **언리얼 레벨 `L_MerchantCamp`**: 벽 8조각으로 사방을 막고, 천장 덮고, 소품 배치, 상인은 모닥불 옆에 세움. 천장이 막혀 햇빛이 없으니 모닥불 불빛을 메인 조명으로 쓰는 것
- 기본 맵도 이 레벨로 바꿔 줌

![Blender로 만든 야영지 모델](https://media.githubusercontent.com/media/Choc1015/NPCProject/main/Docs/Devlog/images/02_camp_blender.png)

![첫 번째 결과](https://media.githubusercontent.com/media/Choc1015/NPCProject/main/Docs/Devlog/images/02_camp_ue.png)

### 중간에 생긴 일

- AI가 블렌더에서 새 파일을 만들다가 **블렌더 MCP 서버를 꺼 버렸음.** 그래서 AI는 블렌더를 화면 없이 백그라운드로 따로 돌려서 모델을 마저 만들었음. 나는 나중에 블렌더에서 MCP 서버를 다시 켜 주면 되는 것
- 모델이 언리얼에 **1/100 크기**로 들어왔음. AI는 일단 배치할 때 100배로 키워서 맞춤

## 2. 피드백: 하늘, 빈 공간, 풀

### 내가 한 것

- 텐트 방향이 마음에 안 들어서 **텐트 방향이랑 땅에 묻힌 부분은 내가 직접 고쳤음**
- 상인 대화는 문제없는 것 확인

### 내가 쓴 프롬프트

> 3. 천장이 지금 나무 색인데 약간 돔 형태로 바꿔서 원근감을 주고 밤하늘 처럼 검은색에 야간 빛나게 바꿔줘
> 4. 공간이 너무 비어있어 오브젝트도 더 추가하고 그렇다고 너무 어지러우면 안되니 비워져 있다고 생각되는 부분은 풀로 채워줘 대신 그냥 풀 오브젝트로 만들어 최적화에 좋지 않으니까 사용이 되면 언리얼 기능인 오브젝트 색칠 기능이 있는걸로 아는데 그걸로 할 수 있으면 해줘

풀을 오브젝트로 하나하나 깔면 최적화에 안 좋다는 건 알고 있어서, **폴리지(Foliage) 페인트**로 해 달라고 한 것.

### AI가 만들어 준 것

- **밤하늘 돔**: 나뭇잎 천장을 빼고 둥근 돔을 올림. 짙은 남색 바탕에 별 400개를 박고, 별 머티리얼을 발광으로 바꿔서 블룸으로 반짝이게 한 것
- **소품 추가**: 모닥불 위 냄비 삼각대, 텐트 옆 랜턴 기둥(작은 불빛 포함), 장작 더미, 자루 더미, 그루터기, 덤불, 버섯
- **풀 메시 3종**: 풀 포기, 키 큰 풀, 꽃. 폴리지로 대량으로 깔 거라 하나에 20~35 삼각형으로 아주 가볍게 만든 것

![밤하늘 돔](https://media.githubusercontent.com/media/Choc1015/NPCProject/main/Docs/Devlog/images/02_camp_sky.png)

### 중간에 생긴 일

- 모델 크기 문제를 고친다고 내보내기 설정을 바꿨더니 이번엔 **100배 크게** 들어왔음. AI가 두 결과를 비교해서 맞는 설정을 계산했고, 세 번째에 정상 크기로 들어온 것
- 블렌더 파일 저장이 막혔는데, 원인은 깃 LFS의 **파일 잠금(lockable) 설정** 때문에 커밋 후 파일이 읽기 전용이 되는 거였음. 혼자 하는 프로젝트라 AI가 그 설정을 뺐음
- **폴리지는 MCP로 못 깔았음.** 지금 연결된 언리얼 MCP에는 폴리지 타입을 만들거나 인스턴스를 까는 기능이 없다고 함. AI는 풀을 개별 오브젝트로 대신 깔지 않고, 풀 메시랑 추천 설정값만 정리해 줌

### 내가 한 것

- **풀은 내가 직접 Foliage 모드로 칠했음.** 풀 메시 3개를 폴리지 패널에 넣고, AI가 알려 준 값(밀도, 랜덤 크기·회전, 콜리전 없음, 그림자 끔, 컬 거리)으로 설정해서 모닥불 주변 흙바닥은 비워 두고 칠한 것

## 3. 벽을 숲으로 두르기

### 내가 쓴 프롬프트

> 그전에 이제 벽면이 너무 허전해 숲속 처럼 둘러 쌓는걸 자연스럽게 만들어줘

풀까지 칠하고 보니 바위 절벽 벽이 너무 밋밋해 보였음.

### AI가 만들어 준 것

- **숲 벽 메시**: 맨 뒤는 아주 어두운 녹색 판으로 빈틈을 막고, 그 앞에 나무줄기·나뭇잎 덩어리·덤불을 여러 겹 겹친 벽 조각. 앞은 듬성듬성, 뒤로 갈수록 빽빽하고 어둡게 해서 숲이 계속 이어지는 것처럼 보이게 한 것
- **나무 3종 추가**: 키 큰 침엽수, 넓은 활엽수, 고사목 + 밑동용 고사리
- 바위 절벽 8개를 숲 벽으로 바꾸고, 벽 앞에 나무 19그루를 두 줄로 들쭉날쭉 세우고 밑동에 고사리 30개를 둘러 줌. 텐트랑 내가 칠한 풀은 안 건드림

### 내가 쓴 프롬프트 (추가)

> 일단 벽면 색이 지금 회색인데 검은색 계열로 해서 우거지게 하자

### AI가 만들어 준 것

숲 벽에만 쓰는 거의 검은 녹색·갈색 머티리얼을 따로 만들어서 벽 메시에만 바꿔 끼움. 앞쪽 나무랑 소품 색은 그대로라서, 뒤는 검은 숲 실루엣이 되고 앞 나무만 어둡게 보이는 것
